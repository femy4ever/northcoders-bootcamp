## Instructions

1. Clone this repo 🐑 - no need to fork 🍴
2. `cd test-psql-setup`
3. Run `npm install`
4. Run `npm run test-psql-setup`
5. If you receive an error message, read it carefully! If you receive a message telling you all is well, read it carefully! 👀
